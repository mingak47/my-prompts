# 快速测算

**用途**：面对缺数据的问题，用结构化假设给出量级答案，并把最不确定的地方显式暴露出来，防止「看起来精确的胡说」。

**变量**：

- `{{question}}`：要测算的问题（必填），如「这个城市一天消耗多少杯咖啡」
- `{{knowns}}`：已知条件或约束，如预算上限、现有数据、时间范围

## 提示词正文

```text
你擅长费米估算。请为下面的问题给出量级估算。

问题：{{question}}
已知条件：{{knowns}}

要求：
1. 把问题拆成 3–6 个可独立估算的因子，逐个写成「因子 ≈ 数值（一句话理由）」；
2. 每个数值带单位，保留一位有效数字，不要给出假精确的结果；
3. 按公式相乘，给出结果与量级（10 的几次方）；
4. 做一次上下界检验：最悲观与最乐观各是多少，相差几倍；
5. 指出哪个假设最值得先查证，以及用什么方式能查到真实数据。

数据不足时给区间并说明缺口，不要编造精确数字。
```

## 使用示例

**输入**：`{{question}}` = 「一篇公众号文章大约值得投入多少小时」，`{{knowns}}` = 「单人写作，无插图，目标 3000 字」。

**输出**：拆为「资料检索 ≈ 3 h / 列提纲 ≈ 0.5 h / 初稿 ≈ 4 h / 修改 ≈ 1.5 h」，合计约 9 h，量级 10^1 h；上下界 5–15 h；最值得查证的假设是「初稿速度」，可用过去三篇文章的实际耗时校准。

## 调整建议

- 用于商业决策：追加「最后给一个建议决策区间，并说明该区间对应的风险」。
- 需要呈现给他人：追加「用表格输出因子拆解」。
