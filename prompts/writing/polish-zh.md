# 中文润色

**用途**：在不改变原意的前提下，把中文草稿改得更通顺、准确、有节奏。适合改稿、改文案、去翻译腔。

**变量**：

- `{{text}}`：待润色的原文（必填）
- `{{style}}`：期望风格，如「正式报告」「公众号」「口语」；留空则用清晰自然的中文

## 提示词正文

```text
你是一位中文编辑。请润色下面的文字，要求：

1. 保留原意、事实、数据和专有名词，不新增观点，不删减信息；
2. 消除语病、冗余和翻译腔，让句子长短交错、读起来有节奏；
3. 风格：{{style}}；未指定时使用清晰自然的中文；
4. 不改变原文的段落结构，除非某段逻辑明显断裂。

只输出润色后的正文，不要解释，不要加标题。

原文：
{{text}}
```

## 使用示例

**输入**：`{{text}}` = 「本方案的主要目的是为了提升效率，减少不必要的浪费。」

**输出**：「本方案旨在提升效率、减少浪费。」

## 调整建议

- 想尽量保留原句：追加「只修语病，尽量少改动」。
- 想看到改了什么：改为「先输出修改点清单，再输出润色稿」。
